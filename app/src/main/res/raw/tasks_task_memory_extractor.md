# 任务：从小说信息中提取长期记忆

分析以下小说的全部信息，提取需要长期记住的重要内容。

## 输入数据
{{full_context}}

## 提取要求
1. **识别重要的剧情转折点或关键事件**
2. **识别角色的重要特征或关系**
3. **识别世界观设定的关键要素**
4. **识别需要保持一致性的设定**
5. **识别对话中提到的新信息（未在角色/设定/大纲中出现的）**
6. **识别用户的特殊偏好或写作要求**

## 返回格式
请返回JSON格式的记忆列表：

```json
{
  "memories": [
    {
      "type": "personality",
      "title": "简短标题",
      "content": "详细内容（可为空）",
      "importance": 3
    }
  ]
}
```

**type可选值：**
- `plot`: 剧情类
- `personality`: 人设类
- `world`: 世界观类
- `other`: 其他类

**importance评分标准：**
- `5`: 核心设定，绝对不能忘记
- `4`: 重要信息，应该记住
- `3`: 一般信息，可以记住
- `2`: 次要信息，可选择性记住
- `1`: 不重要，不应记住

## 注意事项
- 只提取真正重要的信息，不要提取琐碎细节
- 如果某条信息已存在于角色/设定/大纲中，不要重复提取
- **只返回importance >= 3的记忆**
- 直接返回JSON，不要包含其他文字
- 确保JSON格式正确，可以被解析
